# ArcOfMarket 内容写作标准

## 一句话必须提供什么

用户可见文案至少提供以下一项信息：

- 指标名称或计算口径；
- 日期、数值、区间或历史极值；
- 两个指标之间的明确关系；
- 会加强或推翻判断的具体条件；
- 用户点击后能看到的具体内容。

不满足以上任一项的句子删除，不用口号、比喻或悬念补长度。

## 每张图的固定结构

1. **标题**：写指数、指标和时间窗口，不写“命运”“故事”“看清未来”等修辞。
2. **说明**：写数据如何计算、单位是什么、是否包含股息或存在代理口径。
3. **图中数据**：必须包含最新日期和数值，或样本极值与区间。
4. **含义**：说明该指标能回答哪个问题，不能推出什么结论。
5. **变化条件**：写阈值、方向或需要同时确认的第二项数据。
6. **来源与限制**：写发布机构、更新频率、修订和样本偏差。

有数据文件的标准图表由 `chart-facts.ts` 生成第 3 项。无法生成数据事实时，网站构建失败。

## 首页文案

- 标题直接列出当日关键数字，不生成无法复算的“市场温度”。
- 结论后立即列出趋势、广度、集中度和风险输入。
- CTA 写点击后的内容，例如“查看标普与纳指市场广度”，不写“发现更多”。

## 信号文案

公式未冻结时，只能写“正在定义和验证”，不能写“模型正在运行”。

免费页面可以公开策略名称、计划输入、计划频率、可用数据区间和验证状态。以下字段只在
公式冻结、样本外验证完成且订阅开关开启后发布：

- 当前方向；
- 目标仓位；
- 下一触发；
- 失效条件；
- 状态变更原因与提醒。

## 禁止写法

- 没有数字或指标支撑的市场判断；
- “你能确认模型在运行，但看不到……”这类制造悬念的句子；
- 把页面或图表写成“故事”“命运”“答案”“重力”等比喻；
- “值得关注”“洞察未来”“看清今天”等没有具体对象的表述；
- 把计划功能写成已经上线；
- 把代理指标写成官方指数，或把年内数据写成完整年度结果。
