# ArcOfMarket 内容写作标准

## 叙事不是修辞，是事实之间的因果顺序

每个内容单元按以下顺序写：

1. **结论句**：先说读者应该看到的变化，例如“道指领先 QQQ 7.6 个百分点”。
2. **证据**：给出日期、数值、区间、历史极值或计算口径。
3. **历史参照**：说明当前值在历史上的位置，或指出最接近的历史范围。
4. **今天的含义**：解释这些事实怎样改变当前判断。
5. **边界**：明确这组数据不能推出什么。

叙事可以使用轻量比喻，但比喻必须紧跟可核对事实。没有事实支撑的修辞删除。

## 每张图的固定结构

1. **标题**：指标加一个明确结论或问题，不只写数据集名称。
2. **说明**：写数据如何计算、单位是什么、是否包含股息或存在代理口径。
3. **图前结论**：必须包含最新日期和数值，或样本极值与区间。
4. **图后含义**：说明该指标回答了什么，以及今天应怎样理解。
5. **继续观察**：写阈值、方向或需要同时确认的第二项数据。
6. **来源与限制**：写发布机构、更新频率、修订和样本偏差。

有数据文件的标准图表由 `chart-facts.ts` 生成第 3 项，并放到图表之前。无法生成数据事实时，
网站构建失败。

好的标题示例：

- “近一个世纪，涨年比跌年多多少？”
- “年中下跌，不等于全年下跌”
- “七家公司合计占 S&P 500 31.6%”

不合格的标题示例：

- “长期回报”
- “市场概览”
- “看清未来”

## 首页文案

- 标题先说当日最重要的分化，再用数字证明，不能只罗列四个指标。
- 结论后立即列出趋势、广度、集中度和风险输入。
- 把当前变化与历史分位、长期均值或过去完整年度对照。
- 明确区分价格分化、市场广度和金融压力，不把它们压成一个综合分数。
- CTA 写点击后的内容，例如“查看标普与纳指市场广度”，不写“发现更多”。

## 信号文案

公式未冻结时，只能写“正在定义和验证”，不能写“模型正在运行”。

免费页面可以公开策略名称、计划输入、计划频率、可用数据区间和验证状态。以下字段只在
公式冻结、样本外验证完成且订阅开关开启后发布：

- 当前方向；
- 目标仓位；
- 下一触发；
- 失效条件；
- 状态变更原因与提醒。

## 禁止写法

- 没有数字或指标支撑的市场判断；
- “你能确认模型在运行，但看不到……”这类制造悬念的句子；
- 用“命运”“答案”“重力”等词替代本应提供的事实；
- “值得关注”“洞察未来”“看清今天”等没有具体对象的表述；
- 只解释“这张图用于观察什么”，却不说图中实际发生了什么；
- 把计划功能写成已经上线；
- 把代理指标写成官方指数，或把年内数据写成完整年度结果。
