## 四、我们 vs 竞品的核心差异

我们不是 HoM（数据档案），也不是 Klay Wang（信号工具），我们是：

**ArcOfMarket = 市场教育 + 每日判断 + 策略信号**

- **免费层**：全部历史图表 + 教育叙事 = 对标 HoM 的"档案"价值
- **信号层**：首页市场温度 + 策略信号 + Regime Rotation = 对标 Klay Wang 的"温度计"价值
- **付费层**：定制信号、邮件简报、数据导出 = 对标 Klay Wang 的 Standard/Pro

差异化武器：
1. **中文教育叙事** — HoM 没有、Klay Wang 偏技术
2. **四策略信号框架** — 比 K 指数更系统
3. **Regime Rotation** — 六状态量化，可回测
4. **教育框架模块** — Pérez周期、Bernanke政策等，吸引"想学习"的用户
