### 本轮已解决的问题

1. **首页不再只看标普**：同时展示 S&P 500、Nasdaq-100、道指和七巨头等权走势。
2. **市场判断有证据**：趋势、广度与集中度、风险三组读数共同支持首页结论。
3. **信号入口可见但内容不泄露**：免费层说明模型、频率和验证范围；执行值保持锁定。
4. **图表和解释成为同一内容单元**：图下直接说明事实、意义和判断变化条件。
5. **页面结构可配置**：章节顺序、组件和图表引用由 schema 管理，文案独立存放。
6. **数据边界收紧**：Regime Rotation、RS Leaders、Breadth Pulse 原始输出不再复制到 public。

### 仍需遵守的数据限制

- Yale 官方 CAPE 工作簿目前止于 2023-09，不做前向填充。
- 回报拆解目前只有价格与股息，回购仍待可靠来源。
- Forward PE、ROE、AI CapEx 等指标在没有稳定来源前不展示占位数字。

## 四、我们 vs 竞品的核心差异

我们不是 HoM（数据档案），也不是 Klay Wang（信号工具），我们是：

**ArcOfMarket = 市场教育 + 每日判断 + 策略信号**

- **免费层**：历史图表、当前市场事实和逐图解释。
- **信号预览**：展示模型覆盖、更新频率和验证范围，证明产品真实存在。
- **付费层**：当前方向、目标仓位、下一触发、失效条件和状态变更提醒。

具体差异：

1. **比历史图表库多一步**：每张图都回答当前事实、意义和判断变化条件。
2. **比单一温度计多一层证据**：趋势、参与度、集中度和压力指标相互核对。
3. **免费内容能验证，付费内容能执行**：用户能判断研究质量，但拿不到当天交易值。
4. **内容可以持续更新**：数据、页面结构和文字分层管理，后续可接入 AI 文案流程。
