# 数据来源与发布矩阵

本文档供维护者审查数据范围，不直接显示在用户图表下方。用户页面只显示来源、日期、
计算方法和必要声明。

这不是法律意见。免费访问、公开来源和政府网站都不自动等于没有数据、数据库、商标或
再分发限制。实际发布范围由合同、上游条款和逐文件配置共同决定。

## 当前来源

| 来源 | 当前用途 | 项目处理 |
| --- | --- | --- |
| ArcOfMarket 原创方法 | 统计、评分、解释和页面内容 | 可由项目所有人运营和另行授权 |
| FRED | 利率、物价、增长和股票配置 | 使用官方 API，显示要求的 FRED 声明；逐系列检查原始发布者 |
| OFR | 金融压力 | 显示来源与不背书声明 |
| CFTC | VIX 期货持仓 | 保存报告日期和观察时间，显示来源 |
| SEC EDGAR | Form 4、13F | 遵守公平访问；当前文件保持非公开，待覆盖和产品审查 |
| NBER | 美国经济周期日期 | 引用官方日期和方法页面 |
| Wikipedia | 当前成分与变更 | CC BY-SA 4.0，保留修订级归属 |
| Yahoo Finance / yfinance | 价格历史研究输入 | 抓取能力与展示权分开评估；按逐文件政策处理 |
| S&P Dow Jones Indices | S&P 指数与品牌 | 需要关注指数数据和商标展示范围 |
| Nasdaq | Nasdaq 指数与品牌 | 需要关注指数数据和商标展示范围 |
| Cboe | 波动率指数历史 | 需要关注数字媒体展示和衍生数据范围 |
| ICE Data Indices | 经 FRED 交付的信用利差 | FRED 交付不消除 ICE 对具体系列的限制 |

权威机器可读记录位于：

- `config/source-registry.json`；
- `config/dataset-registry.json`；
- `config/public-data-policy.json`；
- `config/subscriber-data-policy.json`；
- `config/fred-series-registry.json`。

## 发布规则

1. 数据文件必须登记一次且只能登记一次；
2. 来源 ID 必须存在；
3. 公开和订阅范围分别默认拒绝；
4. 进入白名单前必须记录依据；
5. 必要来源声明必须进入页面或方法说明；
6. 输入权利不明时，不把对应序列用于付费产品；
7. 原创衍生指标不能绕过上游合同；
8. 不向用户提供可还原完整供应商数据库的下载。

## 已明确的局限

- 当前 S&P 500 成分只能代表抓取日，不能作为历史时点成分数据库；
- 当前 FRED 宏观数据是最新修订版本，不适合无偏的历史回测；
- Forward PE 缺少可持续的一致预期 NTM EPS 输入；
- ETF 代理数据不能命名为官方指数估值；
- 保存 CFTC 与 SEC 快照只能从保存开始形成时点历史；
- 实时行情不在当前产品范围。

## 审查记录

来源或用途变化时，更新 `config/data-license-review.json`，写明审查人、日期、依据和阻断项。
发布门禁只验证记录是否完整，不代替对合同正文的人工判断。
