# 全站页面与图表覆盖

本文档是前端目录、页面组件和数据文件之间的产品契约。竞争产品只用于团队理解市场需求，
不作为代码、文案、命名或布局的实现来源。

## 全站导航

| 顺序 | 页面 | 用户问题 |
| --- | --- | --- |
| 1 | 首页 | 今天应该先看什么 |
| 2 | 宏观 | 资金、物价、增长和金融压力处于什么环境 |
| 3 | S&P 500 | 美国大盘的长期回报与风险如何 |
| 4 | Nasdaq | 成长与科技指数处于什么周期 |
| 5 | Dow Jones | 成熟蓝筹和工业经济表现如何 |
| 6 | 七巨头 | 超大市值公司的集中度和分化如何 |
| 7 | 行业板块 | 指数内部的行业轮动如何 |
| 8 | 实验室 | ArcOfMarket 原创指标给出什么状态 |
| 9 | 全部图表 | 按类型搜索并进入任一图表 |
| 10 | 方法论 / 关于 | 数据从哪里来、图表如何计算 |

左侧主导航负责跨页面跳转。每个长页面顶部只显示本页图表目录，不重复全站导航。移动端
目录使用可横向滚动或底部浮层，保持图表锚点容易访问。

## 宏观

- 政策利率：SOFR、EFFR 与目标利率；
- 国债期限结构；
- 10Y−2Y 利差；
- CPI、核心 PCE 与 PPI；
- 实际 GDP；
- 非农与失业率；
- 股票配置占比；
- OFR 金融压力；
- CFTC VIX 期货仓位；
- 高收益与投资级信用利差。

每张图表必须显示日期、单位、来源和 latest-vintage 或快照限制。

## 行业与主题

基础行业页面覆盖 11 个 GICS 板块。专题页面包括半导体、信息技术、金融、消费、通信、
医疗、工业、能源、公用事业、房地产、材料和奢侈品。

每个专题优先使用相同的阅读模板：

1. 长期路径；
2. 年度回报；
3. 年内回撤；
4. 相对强弱；
5. 内部持仓或公司分化；
6. 方法和数据来源。

## 实验室

实验室只承载 ArcOfMarket 原创研究：

- 市场状态；
- 轮动强度；
- 宽度与动量；
- 相对强弱领导者；
- 未来新增的风险、仓位和流动性指标。

每个指标需要版本、输入、公式摘要、状态解释、局限和变化台账。没有定义完成的指标不以
空图或临时名称发布。

## 组件验收

一个目录条目只有在同时满足以下条件时才能加入：

- 页面存在对应锚点；
- 锚点包含可渲染图表或清楚的数据不可用说明；
- 数据文件已登记并进入正确白名单；
- 图表标题、单位、频率和来源完整；
- 桌面与移动端均可访问；
- 生产构建的图表目录审计通过。
