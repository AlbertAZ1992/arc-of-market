## 1. 产品结构

ArcOfMarket 不是“把 120 张图放到网页上”，而是帮助用户依次回答五个问题：

1. 今天市场发生了什么？
2. 这件事处于哪一段历史和周期？
3. 风险正在扩散还是收敛？
4. 哪些资产、行业和公司正在成为主角？
5. 我现在应该观察什么，什么时候需要行动？

前四个问题主要由公开研究回答。第五个问题由付费策略信号回答。

- 免费内容卖“看懂市场”；
- 付费内容卖“持续监控、明确状态、触发条件与提醒”；
- 所有图表都进入全量目录；
- 首页和研究页只选择能完成当前叙事的图。

## 3. 导航

### 3.1 固定主导航

保留现有窄左栏，只放六个入口：Today、Markets、Sectors、Signals、Archive、About。
悬停时展开标签；当前栏目用红色短线和实心状态表示。窄栏不承担章节导航。

### 3.2 Codex 式页内轨道

```text
— 今日结论
│
— 历史位置
│
━━ 周期与风险    ← 当前章节
│
— 结构与主角
│
— 接下来观察
```

- 默认只显示短横线；
- 悬停浮出章节名和一句摘要；
- 点击滚动到章节；
- 当前章节使用深色长线；
- 重要变化可有一个红点，不能整条变红；
- 移动端改为顶部横向章节条。

## 4. 页面模板

### 首页

```text
日期和数据时间 → 一句话判断 → 三个关键事实 → 策略信号预览
→ 今日五幕叙事 → 接下来观察 → 继续研究 → 订阅
```

首屏同时出现判断、三个事实、四个信号轮廓和第一张关键图的开头。

### 市场研究页

```text
页面命题 → 当前结论 → 关键数字 → 长期历史 → 回报与分布
→ 风险与回撤 → 估值与基本面 → 结构与主角 → 接下来观察
```

每章先给结论句，再给一张主图，最后最多两张证据图。

### 行业页

```text
行业状态 → 相对大盘强弱 → 周期位置 → 风险与回撤
→ ETF / 指数内部结构 → 领导者与落后者 → 观察清单
```

### 策略页

```text
当前状态 → 最近变化 → 历史表现边界 → 触发条件
→ 失效条件 → 模型证据 → 提醒与订阅
```

### Archive

```text
搜索 → 市场 / 问题 / 时间 / 状态筛选 → 121 张图目录
→ 图表详情 → 数据来源和更新时间
```

## 5. 首页逐模块设计

### 一句话今日判断

只允许一句主判断和一句限定语。配套显示市场状态、主导资产、风险温度和数据时间。

### 三个关键事实

每个事实必须包含指标值、方向变化、历史分位和一句“这意味着什么”：

1. 趋势：SPY / QQQ 距 200 日线、滚动回报或创新高比例；
2. 风险：回撤、波动率、信用利差或金融压力；
3. 领导力：广度、集中度、行业相对强弱。

### 顶部策略信号

四张横向状态卡：

```text
QQQ Quant        模型状态发生变化     2 天前更新
Momentum         趋势仍在延续         强度 78/100
QQQ / VTV        接近反转观察区       分位 91%
Perez Cycle      基础设施 → 部署期     置信度中
```

免费展示策略名称、状态类别、是否变化、信号年龄、归一化强度和历史区间描述。
订阅后展示当前状态和仓位、切换时间、触发阈值、失效条件、检查点、提醒和 Ledger。

### 今日五幕

首页每天从全量图表动态选择 6–10 张：

1. 长期方向：长期总回报 + 滚动五年回报；
2. 当前周期：牛熊周期 / Arc Regime + 收益率曲线；
3. 风险扩散：年内回撤 + VIX / 信用利差 / 广度；
4. 谁在主导：头部权重 + Mag 7 分化 / 行业强弱；
5. 接下来观察：环境总览 + 三个可能推翻判断的阈值。

首页不展示空图、接口错误、内部合规文案、未完成图表、全量瀑布流或完整仓位。

## 10. Archive 与数据状态

数据范围、更新时间、状态、来源和版本。

| 内部状态 | 用户看到的内容 |
|---|---|
| 正常 | 图表与更新时间 |
| 暂无最新值 | 上一可用值和截止时间 |

| 图表未完成 | 不进入生产目录 |

任何页面都不得渲染只有标题和空白坐标轴的“空图表”。

## 13. Figma 画板

Figma v1 包含五个可编辑画板：

1. `Sitemap`：全站层级、免费 / 付费边界、首页到订阅路径；
2. `首页 Desktop`：窄左栏、判断、关键事实、信号预览和五幕开头；
3. `研究页模板`：以 S&P 500 展示五幕、主图 / 证据图和页内轨道；
4. `Strategy Signals`：四策略总览、付费边界、触发和失效信息；
5. `Mobile Navigation`：收起主导航、横向章节、信号横滑和单列图表。

## 14. 验收标准

- 用户 10 秒内能说出今天的市场判断；
- 用户知道下一张图为什么值得看；
- 长页始终知道自己处于哪个章节；
- 任何登记图都能在 Archive 找到；
- 免费用户能理解策略价值，但看不到完整仓位、阈值和执行时间；
- 生产页面零空图、零接口文案、零内部合规文案；
- 每张图都有问题句、结论句、数据范围和更新时间；
- 所有 121 张登记图都有 owner、状态和页面归属。
