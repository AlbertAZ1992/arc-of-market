# 道琼斯分析套件设计

## 产品位置

道琼斯页面放在“标普 500 → 纳斯达克 → 道琼斯 → 七巨头”的阅读顺序中。
它回答的不是“美国市场整体发生了什么”，而是三个更具体的问题：

1. 三十只价格加权蓝筹与市值加权大盘有何不同？
2. 道指回报由哪些公司和行业推动？
3. 蓝筹风格在不同经济周期中的表现如何？

页面沿用现有 Anyway 风格版式、底部图表索引和 ECharts 组件，不新增一套视觉语言。

每日工作流更新价格、波动、回撤、权重、热力图和贡献；年度与持有期图表由同一批
日线重新计算。每个文件保留 `as_of`、实际覆盖区间、计算方法和数据源。

## 数据边界

- 首版只展示当前成分及其当前价格权重，不用当前成分倒推历史指数。
- 历史调入调出只有在找到可追溯的逐条来源后再上线。
- 不展示实时逐笔行情，页面使用每日收盘快照。
- 不把 DIA 复权价格写成官方 DJIA Total Return Index。
- 页面只呈现读者需要的来源、日期和口径说明；内部授权审计状态不进入图表文案。

## 实施顺序

1. 把现有指数计算函数抽成可配置的 `build_index_suite`。
2. 为 `^DJI` 生成十二个标准历史面板，并加入数据注册表与公开策略。
3. 获取当前三十只成分，生成价格权重、行业结构和贡献近似。
4. 新建完整的 `/dow/` 页面和底部图表索引。
5. 把全部 Dow 文件加入构建期图表覆盖审计。
6. 运行数据、类型、构建与浏览器滚动验收后分批提交。
