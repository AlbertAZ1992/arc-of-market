# 产品蓝图

## 定位

ArcOfMarket 不是行情终端，也不是荐股服务。它把分散的市场事实组织成一条稳定阅读路径：

```text
宏观环境 → 大盘指数 → 成长指数 → 蓝筹指数 → 头部公司 → 行业轮动 → 原创状态
```

免费站建立信任和使用习惯；订阅产品节省用户理解、监控和复盘市场的时间。

## 核心用户

- 希望系统学习美股，但不熟悉英文数据源的个人投资者；
- 已经持有 ETF，需要理解市场环境和历史位置的长期投资者；
- 需要高质量中文图表和简报的内容创作者；
- 需要统一研究桌面的专业从业者。

## 免费产品

### 市场档案

- S&P 500、Nasdaq 和 Dow Jones 长期统计；
- 当前成分、行业结构和成分变更；
- 七巨头与行业主题；
- 图表搜索和下载；
- 完整方法、来源和局限说明。

### 宏观仪表盘

- 利率与期限结构；
- 通胀与增长；
- 就业；
- 金融压力与信用；
- 仓位和配置代理；
- 经济周期背景。

免费页面不依赖实时行情，允许使用日频、周频或月季频率，只要明确更新时间。

## 订阅产品

### 每日状态

把宏观、趋势、宽度、波动、轮动和相对强弱压缩为少量原创状态：

- 当前区间；
- 相比昨日和上周的变化；
- 触发变化的主要维度；
- 历史相似状态；
- 需要继续观察的条件。

### 简报

- 盘前：隔夜变化、宏观日历和关键阈值；
- 盘后：指数、行业、宽度和风险变化；
- 周报：状态迁移、历史对照和下周观察；
- 季度：13F、盈利环境和市场结构专题。

### 提醒

提醒围绕状态变化，不围绕“买入/卖出”指令：

- 状态跨区间；
- 趋势或宽度背离；
- 波动结构显著变化；
- 行业领导者变化；
- 宏观数据超出历史区间。

### 编辑产品

将主要结论生成一张可直接转发的杂志型长图。长图包含日期、核心状态、三到五张小图、
方法链接和风险提示。

## 付费价值

用户付费购买：

- 持续计算；
- 多源信息压缩；
- 原创解释框架；
- 变化监控；
- 版本稳定的研究流程；
- 节省时间的简报和图卡。

用户不购买：

- 原始 Yahoo、FRED、SEC 或其他供应商文件；
- 对未来收益的保证；
- 个性化投资建议；
- 无法解释来源的黑箱分数。

## 数据产品边界

公开图表和订阅指标使用不同白名单。订阅输出采用评分、状态、分位、摘要和提醒，避免提供
可逆的完整原始序列。每项原创指标保留输入来源和版本记录，以便在供应商或方法变化时重算。

## 视觉与交互

- 中文正文使用思源宋体，英文衬线使用 Merriweather；
- 界面文字使用思源黑体与 Open Sans；
- 数字与代码使用 Fira Mono；
- 宽松留白、编辑式分栏、清晰编号和克制色彩；
- 左侧导航负责全站，本页图表目录位于页面头部；
- 移动端优先保证图表标题、当前读数、时间范围和目录可用；
- 不依赖插画，用排版、数据和图表形成品牌。

## 成功指标

- 数据任务成功率和数据新鲜度；
- 图表页面访问深度；
- 用户从首页进入第二个研究页面的比例；
- 图表下载和分享次数；
- 简报打开率；
- 提醒后的回访率；
- 免费用户转订阅和订阅留存；
- 来源或数据质量事故为零。
