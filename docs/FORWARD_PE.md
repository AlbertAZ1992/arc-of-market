# Forward PE 数据契约

## 定义

S&P 500 Forward PE 的基本计算为：

```text
Forward PE = 当前指数点位 ÷ 未来十二个月一致预期指数 EPS
```

分子和分母必须对应同一指数口径与相近时点。分母是分析师一致预期的
next-twelve-months EPS，不是过去十二个月 EPS、历史增长趋势或单一公司的预测。

## 为什么当前不能自动补齐

指数点位容易获得，但可靠的一致预期指数 EPS 通常来自专业基本面供应商。网页估值、
历史 EPS、管理层指引或把历史趋势向前延伸，都不能替代一致预期 NTM EPS。

因此项目只保留计算与校验能力，不生成一个看似完整但口径错误的生产序列。

## 输入字段

取得合适数据后，通过受保护的运行环境提供：

| 变量 | 含义 |
| --- | --- |
| `SP500_FORWARD_EPS_NTM` | 正数，一致预期未来十二个月指数 EPS |
| `SP500_FORWARD_EPS_AS_OF` | 供应商快照日期，ISO 日期 |
| `SP500_FORWARD_EPS_SOURCE` | 供应商和具体产品名称 |
| `SP500_FORWARD_EPS_LICENSE_SCOPE` | `internal` 或 `public` |

输入超过 45 天会被判定为过期。日期不能在未来，EPS 必须大于零。`public` 只表示项目配置
声称已取得公开展示范围；正式发布前仍须把合同或书面依据登记到数据审查记录。

## 供应商验收

采购时应书面确认：

- 是否提供 S&P 500 指数级 NTM EPS，而非成分股简单加总；
- 预测聚合、币种、稀释口径和异常值处理；
- 历史序列是否是当时可见的 point-in-time 快照；
- 网站图表展示、衍生比率、缓存和订阅产品使用权；
- 是否允许保存历史快照；
- 终止合同后已有历史数据如何处理。

## 输出要求

未来启用时，每个输出点至少应记录：

- 指数点位及日期；
- NTM EPS 及快照日期；
- Forward PE；
- 来源、许可范围和生成时间；
- 是否为 point-in-time；
- 数据是否超过新鲜度阈值。

如果只有最新 EPS 快照，只能展示当前值，不能把当前预测回填到历史日期制造伪历史曲线。
