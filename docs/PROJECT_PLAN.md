# 项目计划

## 产品目标

ArcOfMarket 要成为中文用户理解美国市场的长期档案和每日研究入口。免费层提供可靠、
可搜索、可复核的图表；订阅层提供原创状态判断、变化提醒和编辑型研究产品。

## 当前基线

- Python 数据管线、失败回滚、数据审计和哈希链可运行；
- Astro 全站框架、长页目录和主要指数图表已实现；
- 宏观、S&P 500、Nasdaq、七巨头和行业主题已建立页面；
- 数据来源、逐文件登记、公开白名单和订阅白名单已分离；
- GitHub Actions 支持日更、周更、CI 和静态部署；
- 不可靠的旧估值、情绪和期权派生数据已移出生产仓库。

## P1：稳定公开站

- 验证所有现有数据的自动更新；
- 为每个图表补齐来源、日期、单位和方法说明；
- 完成 Dow Jones 数据与图表；
- 修复移动端目录和图表可读性；
- 建立更新失败、数据过期和构建失败告警；
- 完成仓库历史净化和生产部署重连。

完成标准：所有公开目录条目都有真实图表，日更和周更连续四周成功，任何阻断数据失败均
不会发布半成品。

## P2：原创研究产品

- 定义市场状态、轮动、宽度和相对强弱指标；
- 为每项指标建立版本、输入和状态台账；
- 设计盘前、盘后和周度简报；
- 生成可转发的编辑型长图；
- 对提醒和回测口径建立明确限制。

完成标准：订阅用户购买的是解释、变化和工作流，不是上游原始数据。

## P3：订阅基础设施

- Next.js 应用壳；
- Cloudflare Workers、D1 和 R2；
- Better Auth；
- Stripe 订阅；
- 邮件或消息提醒；
- 订阅数据门禁和访问审计。

实施前提：订阅输入的来源和合同范围已逐项确认，原创指标已经有持续更新记录。

## 数据优先级

1. 保证现有日更、周更稳定；
2. 完成 Dow Jones 所需历史和当前成分数据；
3. 保存每次 CFTC、SEC 和成分变更快照；
4. 评估可展示的一致预期 EPS 供应商；
5. 评估商业价格和指数数据供应商；
6. 不采购时，使用权利清楚的 ETF 代理并明确标识；
7. 不为填满页面而引入来源不明的数据。

## 发布纪律

- 一次提交只处理一个逻辑改动；
- 每次提交前运行相关测试、lint 和类型检查；
- 不直接推送 `main`；
- 自动数据只提交到专用分支；
- 密钥只存在本地 `.env` 和 GitHub Secrets；
- 来源条款变化时先停止相应发布，再评估替代方案。
